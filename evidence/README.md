# Evidence directory

Only sanitized, synthetic or explicitly public-safe receipts belong here.

Each future receipt must state:

- exact component and version;
- environment class without private identifiers;
- command or test path;
- expected and observed result;
- whether the result is live, offline, simulated or partial;
- limitations and expiry/last-verified date;
- confirmation that no secrets or employer/customer data are present.
